# kids-places

This project contains the imported Family Explorer app, added under the kids-places project folder, with the files needed to run it locally in VS Code.

Original AI Studio app: https://ai.studio/apps/4f6438d7-28ed-4623-b6a9-1c88a571ae8a

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies:
   `npm install`
2. Optionally create `.env.local` from `.env.example` if you add runtime secrets later.
3. Run the app:
   `npm run dev`
4. Open `http://localhost:3000`
